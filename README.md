# meme-plugin

给 Yunzai 装上表情包。群里发 `#摸头 @某人`，机器人就把头像做成表情发出来。

**944 个表情 · 1332 个名字 · 33 个分类**（取决于装了哪些表情包）。

## 能玩什么

- 中文指令出图：`#摸头`、`#一巴掌 笨蛋`、`#高低情商 会说话/不会说话`
- 网页版：翻真图预览，还能直接在网页上做图
- `#meme搜索 猫` 出九宫格真图；`#meme列表` 分页翻
- `#抽个cp` 随机配对群友、`#整活 @某人` 连出 6 个表情
- `#套娃 摸头 踩 恐龙` 把头像一层层叠进表情里、`#全群摸头` 随机几个群友一起做
- `#今日表情` 每天固定一个表情配运势、`#猜表情` 出图让群友猜名字得分
- `#meme排行` 看本群谁最能整活，`#meme总排行` 所有群一起排；撅主人会被反撅 🙂
- 群开关、拉黑人 / 拉黑表情、`#meme更新` 一句话升级

## 装起来

**① 下载插件** —— 在云崽根目录执行

```bash
git clone --depth=1 https://gitcode.com/ccxhan/meme-plugin.git ./plugins/meme-plugin
# GitHub 也行：https://github.com/cchanlan/meme-plugin.git
```

重启即可，**不用装依赖**（用的都是 Yunzai 自带的）。

**② 配一个「画图服务」** —— 这步跑不掉，见下一节

**③ 群里发 `#摸头` 试试**，出图就成了。

## 画图服务

插件自己不画图，它把 `#摸头` 翻成请求交给 **meme-generator** 去画。三种情况对号入座：

| 你的情况 | 怎么做 |
| --- | --- |
| 别人给了你地址 | 填进配置 `memeApiUrl`，完事。表情仓库、`#meme部署`、`reposDir` 全都不用管 |
| 机器上还没有 | 发 `#meme部署`（主人限定），自动建环境 + 拉 5 个仓库 + 挂后台。需要 Python 3.9+、git、pm2；约占 2G，等几分钟正常；反复发不会重复装 |
| 早就装过 | `memeApiUrl` 指向它，**并且一定要填 `reposDir`**（表情仓库目录，常见 `/opt/meme`） |

> ⚠️ 第三种情况不填 `reposDir` 的话，`#meme更新` 会另外下一份，你更新的是新下的、画图服务读的是老的——
> **看着成功其实没生效**，还白占几个 G。

撤掉发 `#meme卸载`（会先列清单让你确认，默认不删表情仓库）。
想完全手动部署见 [docs/技术细节.md](docs/技术细节.md)。

## 指令

### 做表情

| 发什么 | 效果 |
| --- | --- |
| `#摸头` / `#摸头 @某人` | 用自己 / 对方的头像 |
| 引用图片再发 `#摸头` | 用那张图 |
| `#一巴掌 笨蛋` | 带一段文字 |
| `#高低情商 会说话/不会说话` | 多段文字用 `/` 隔开 |
| `#爬#33` / `#一直#循环` | 第二个 `#` 后面写参数值或选项名 |
| `#摸头详情` | 出图说明这个表情要几张图、几段文字、能调什么 |

### 整活与查找

| 发什么 | 效果 |
| --- | --- |
| `#抽个cp` | 随机抽两个群友配双人表情（30 多个），可 @ 固定一位或两位 |
| `#整活 @某人` | 拿他头像连做 6 个表情，合并转发发出（`#表情轰炸` 同效） |
| `#套娃 摸头 踩 恐龙` | 头像套进第一个表情，成品再套下一个，一层层叠。不写表情名就随机叠（会自动挑动图，别叠出一张不动的） |
| `#全群摸头` | 同一个表情，随机几个群友的头像各做一张，一条消息全发（`#全员` `#全体` 同效） |
| `#今日表情` | 同一个人同一天永远是同一个表情，配一句今日运势 |
| `#猜表情` | 出一张用你头像做的表情，限时说出名字得一分；`#猜表情排行` 看榜 |
| `#meme搜索 猫` | 九宫格真图，多了会附一份可复制的名字列表 |
| `#meme列表` / `#meme分类 学习` | 分页翻 / 按分类看，也可点机器人给的网页链接 |
| `#meme新增` | 最近更新的表情，带真图 |
| `#随机meme` | 随便来一个 |
| `#meme排行` | 本群整活排行，带头像和 7 天趋势 |
| `#meme总排行` | 跨群总榜，多带一个最活跃的群 |
| `#meme帮助` | 指令菜单 |

### 管理（主人 / 群管）

| 发什么 | 效果 |
| --- | --- |
| `#meme开启` / `#meme关闭` / `#meme开关` | 本群开关与当前状态 |
| `#meme更新` | 拉新表情、必要时重启服务、刷新列表 |
| `#meme重载` / `#meme清缓存` | 只刷列表 / 清出图缓存 |
| `#meme插件更新` / `#meme版本` | 升级插件本体、看版本 |
| `#meme部署` / `#meme部署状态` / `#meme卸载` | 装 / 查 / 卸画图服务 |
| `#meme排行` `#meme总排行` `#meme清空统计` | 本群榜 / 跨群总榜 / 清零 |

拉黑某个人、屏蔽某个表情是**改配置**（`blackUsers` / `blackMemes`），不是指令。

## 网页版

机器人会给一个带 token 的链接，页面上能翻全部表情真图、按分类筛、在线做图。
端口和对外网址在配置里改（`webPort`、`webUrl`），不想要就 `enableWeb: false`。

## 配置

改 `config/config.yaml`，或装了锅巴就在面板里点。常用几项：

| 配置 | 默认 | 干什么的 |
| --- | --- | --- |
| `memeApiUrl` | `http://127.0.0.1:2233` | 画图服务地址，**最重要的一项** |
| `reposDir` | 空 | 表情仓库目录；用现成服务时必填，见上面的警告 |
| `forceSharp` | `true` | 指令要不要带 `#` |
| `enableWeb` / `webPort` / `webUrl` | `true` / `3132` / 空 | 网页版开关、端口、对外网址 |
| `enableFun` / `funCooldown` / `comboCount` | `true` / `20` / `6` | 整活开关、群内冷却秒数、一次做几个 |
| `nestMaxSteps` / `nestMaxSize` | `3` / `4` | 套娃最多叠几层、单层超过几 MB 就停手 |
| `crowdCount` | `6` | `#全群摸头` 抽几个群友 |
| `enableGuess` / `guessTimeout` | `true` / `60` | 猜表情开关、一局时限（秒） |
| `masterProtect` | `true` | 撅主人会被反撅 |
| `blackUsers` / `blackMemes` | 空 | 拉黑的人 / 表情 |

其余（超时、分页数、预览数量等）见 `config/default_config.yaml`，都有中文注释。

## 出问题先看这几条

- **一直「服务连不上」** —— `memeApiUrl` 填错，或画图服务没起来（`pm2 ls` 看看）
- **更新了但表情没变多** —— 十成是 `reposDir` 没填，见上面的警告
- **网页打不开** —— `webUrl` 没填对外地址，或端口没放行
- **发不出图** —— 一次转发太大（比如上百张），把 `comboCount` 调小
- 其余排查见 [docs/技术细节.md](docs/技术细节.md)

## 数据在哪

配置在 `config/`，统计与黑名单在 `data/`，出图缓存在 `temp/`。表情素材在画图服务那边（`reposDir`）。
