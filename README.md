# meme-plugin

给 Yunzai 机器人装上表情包。群里发一句 `#摸头 @某人`，机器人就把头像做成表情发出来。

现在能玩 **944 个表情**、认 **1332 个名字**、分 **33 个类**（具体数量看你装了哪些表情包）。

## 能玩什么

- **群里发指令出图** —— `#摸头`、`#一巴掌 笨蛋`、`#高低情商 会说话/不会说话`，全是中文名，不用记英文
- **有个网页版** —— 不知道都有啥表情？打开网页一页页看真图，还能**直接在网页上做图**存到手机
- **找得到** —— `#meme搜索 猫` 出一张带真实预览图的九宫格；`#meme列表` 一页页翻
- **名字不会打错** —— 「摸鱼」不会被「摸」抢走，长名字优先
- **管得住** —— 某个群不想玩就 `#meme关闭`；有人刷屏就拉黑他；表情太黄就拉黑它
- **有排行榜** —— `#meme排行` 出图看群里谁最能整活，带头像和最近 7 天趋势
- **撅主人会被反撅** —— 默认开着 🙂
- **更新一句话** —— `#meme更新` 自动拉新表情、重启服务、刷新列表，不用重启机器人

## 三步装好

**① 把插件下载到 Yunzai 的 plugins 目录**

```bash
cd Yunzai/plugins
git clone https://gitcode.com/ccxhan/meme-plugin.git
# GitHub 也行：git clone https://github.com/cchanlan/meme-plugin.git
```

然后重启 Yunzai。**不用装任何依赖**，插件用的都是 Yunzai 自带的东西。

**② 给它配一个「画图的程序」** —— 见下面一节，这步跑不掉

**③ 群里发个 `#摸头` 试试**

出图了就成了。想看都有啥表情，发 `#meme列表`，或者点机器人发的网页链接。

以后插件本身要升级，发 `#meme插件更新`（只有主人能发），它自己拉代码、必要时重启。

## 为什么还要配个东西？

因为这个插件**自己不会画图**。它更像个遥控器：把你在群里发的 `#摸头` 翻成一条请求，
交给一个叫 **meme-generator** 的程序去画，画完拿回来发到群里。下面把它叫「画图服务」。

三种情况，对号入座：

### ① 别人直接给了你一个地址

形如 `http://1.2.3.4:2233`。最省事：把它填进配置里的 `memeApiUrl`，完事。

这种情况下，**表情包仓库、`#meme部署`、`reposDir` 这些全都跟你无关**，一个字都不用看。
`#meme更新` 也会自己认出来「服务不在我这台机器上」，只帮你把对方的新表情同步进列表，
不会傻乎乎去下载好几个 G 的素材。

### ② 你机器上还没有，想让插件自己装

发 `#meme部署`（只有主人能发），它会自动建环境、装程序、拉 5 个表情包仓库、把服务挂到后台。

- 需要机器上有 **Python 3.9 以上、git、pm2**（pm2 是让程序常驻后台的小工具，
  `npm i -g pm2` 就能装），缺哪个它会明确告诉你
- 装完大概占 **2G**，大部分时间花在下表情素材上，等个几分钟是正常的
- 反复发也没关系，装到哪儿算哪儿，不会重复装
- 要是它发现你**已经有一套能用的服务**了，会先拦一下告诉你「不用重复装」；
  真想再装一套独立的就发 `#meme部署确认`（用另一个 pm2 名字，不动现有那套）
- 想撤掉发 `#meme卸载`，它会先列一张「要删什么、不动什么」的单子让你确认。
  默认**不删表情包仓库**（好几个 G，重装还得再下一遍），真要一起删就发 `#meme卸载全部确认`

### ③ 机器上早就装过 meme-generator

把 `memeApiUrl` 指向它，另外**一定要填 `reposDir`** —— 就是那些表情包仓库放在哪个目录
（常见的是 `/opt/meme`）。不填的话 `#meme更新` 会另外下一份，你更新的是新下的那份，
画图服务读的还是老那份，**看着更新成功了其实没生效**，白占几个 G。

> 想完全自己动手装画图服务（不用 `#meme部署`），命令和注意事项在
> [docs/技术细节.md](docs/技术细节.md) 的「手动部署」一节。

## 指令表

### 做表情

| 这样发 | 效果 |
|---|---|
| `#摸头` | 用你自己的头像 |
| `#摸头 @某人` | 用对方的头像 |
| 引用一张图片，再发 `#摸头` | 用那张图 |
| `#一巴掌 笨蛋` | 带一段文字 |
| `#高低情商 会说话/不会说话` | 多段文字用 `/` 隔开 |
| `#爬#33` | 有些表情能调参数，第二个 `#` 后面写值 |
| `#一直#循环` | 参数是几个固定选项时，直接写选项名 |
| `#摸头详情` | 出一张图，告诉你这个表情要几张图、几段文字、能调什么 |

不确定某个表情怎么用，就先发 `#它的名字详情` 看一眼。

### 找表情

| 这样发 | 效果 |
|---|---|
| `#meme搜索 猫` | 出九宫格真图，多了会另外附一份能复制的名字列表 |
| `#meme列表` / `#meme列表 3` | 一页 24 个翻着看 |
| `#meme分类` | 有哪些类，每类多少个 |
| `#meme分类 鸣潮` | 看这一类都有什么 |
| `#随机meme` | 随便来一个 |
| `#meme排行` | 用量榜：表情榜 + 玩家榜 + 最近 7 天趋势 |
| `#meme帮助` | 出一张完整说明图 |

### 管理（主人 / 群管）

| 这样发 | 谁能发 | 效果 |
|---|---|---|
| `#meme关闭` / `#meme开启` | 群管、主人 | 只管这一个群。关掉后表情指令**一声不响**，不会回「本群已关闭」再刷一遍屏 |
| `#meme开关` | 所有人 | 看本群现在是开还是关 |
| `#meme更新` | 主人 | 拉新表情。自动走完「下载 → 登记 → 重启画图服务 → 刷新列表」，不用重启机器人 |
| `#meme刷新` | 主人 | 只重新读一遍表情列表，不下载。服务那边已经是新的时用这个更快 |
| `#meme部署状态` | 主人 | 一张体检报告：服务通不通、有多少表情、环境齐不齐 |
| `#meme清缓存` | 主人 | 手动清预览图缓存（平时每 6 小时自己清一次） |
| `#meme清空统计` | 主人 | 排行榜清零 |
| `#meme部署` | 主人 | 在这台机器上装一套画图服务 |
| `#meme卸载` | 主人 | 上面那条的反操作。**插件里唯一会删东西的指令**，会先让你确认 |
| `#meme插件更新` | 主人 | 更新**插件本身**（不是表情）。拉不动时用 `#meme插件强制更新` |
| `#meme版本` | 主人 | 看看现在什么版本、有没有新的 |

> **`#meme更新` 和 `#meme插件更新` 是两回事**：前者拉**表情**，后者拉**插件代码**。
> 看清楚有没有「插件」两个字。

指令前面的 `#` 可以用配置 `forceSharp` 去掉，但去掉之后聊天里随口说个「摸头」也会触发，**建议留着**。

## 网页版

装好之后机器人所在的机器上会开一个小网站，默认地址 `http://你的地址:3132`，
群里发列表、搜索时附的那个链接就是它。不想要就把配置 `enableWeb` 关掉。

网页上能做的事：

- 挨个看每个表情长什么样，边划边加载，手机上也不卡
- 搜框里可以搜中文名、分类、英文代号
- 点一下卡片就把指令复制走，回群里直接粘
- 新拉的表情排在最前面
- **在线做图**：点开某个表情 → 传张图（或者填个 QQ 号直接用他头像）→ 填字 → 出图，长按保存

> 做出来是**动图**的时候，别用浏览器右键的「复制图像」—— 那样粘到 QQ 只剩第一帧变成静态图，
> 任何网站的动图都这样，不是做坏了。**存成文件再发**，或者手机上长按图片保存。

这个网站是**公开的、不需要密码**，里面只有表情图片，没有你的隐私。
但「在线做图」是唯一会占用机器算力的入口，所以做了限制：每个 IP 每分钟最多做 10 次
（配置 `webMakeLimit`），同时最多做 2 张。不想让别人用就把 `enableWebMake` 关掉。

要让家人朋友从外网访问，得把配置 `webUrl` 填成你的公网地址，并且在防火墙放行这个端口。

## 不想让某些人/某些表情出现

三个地方可以管，都能在锅巴面板里点，也能直接改 `config/config.yaml`：

| 想干什么 | 改哪个 | 说明 |
|---|---|---|
| 某个群别玩了 | 群里发 `#meme关闭` | 存的是「关掉的群」，所以新进的群默认是开的 |
| 某个人别玩了 | `blackUsers` 填 QQ 号 | 他发指令一律不理，也**不会回提示** —— 回一句话反倒给了他刷屏的借口 |
| 某个表情别出现了 | `blackMemes` 填名字 | 填中文名（`摸头`）或英文代号（`petpet`）都行 |

拉黑表情是**整个表情**一起拉黑，它的其他别名也一起失效，没法换个名字绕进来。
搜索、列表、分类、随机、网页版全都查不到，配一处就够。

## 配置

用锅巴面板点着改最方便（改完立刻生效，不用重启），也可以直接改 `config/config.yaml`。

**大多数人只会动这几个：**

| 配置 | 默认 | 干什么的 |
|---|---|---|
| `memeApiUrl` | `http://127.0.0.1:2233` | 画图服务的地址，**最重要的一项** |
| `forceSharp` | `true` | 指令要不要带 `#` |
| `replyWithQuote` | `false` | 发表情时要不要引用回复 |
| `masterProtect` | `true` | 撅主人会被反撅 |
| `blackUsers` | 空 | 拉黑的 QQ 号 |
| `blackMemes` | 空 | 拉黑的表情 |
| `enableWeb` | `true` | 网页版开关 |
| `webPort` | `3132` | 网页版端口 |
| `webUrl` | 空 | 对外网址，群里发的链接用它，留空就是 localhost |
| `enableWebMake` | `true` | 网页上的「在线做图」开关 |

**平时不用动的：**

| 配置 | 默认 | 干什么的 |
|---|---|---|
| `apiTimeout` | 30000 | 一次请求最多等多少毫秒 |
| `imageTimeout` | 15000 | 下一张图最多等多少毫秒 |
| `maxFileSize` | 10 | 收多大的图（MB），超了直接不收 |
| `pageSize` | 24 | `#meme列表` 一页几个 |
| `searchMaxPreview` | 24 | 搜索/分类最多出几个图 |
| `tagMinCount` | 2 | 少于几个表情的分类就不显示了 |
| `webMakeLimit` | 10 | 网页做图，每个 IP 每分钟几次 |
| `enablePreviewCache` | `true` | 预览图存本地（建议开，不然每次都要重新拿） |
| `maxCacheMB` | 300 | 预览图缓存最多占多少（原图和缩略图各算一份），满了自动删最久没看的 |
| `protectList` | 41 项 | 「反撅主人」对哪些表情生效 |
| `disabledGroups` | 空 | 关掉了表情的群，一般由 `#meme关闭` 自己维护 |
| `serviceMode` | `auto` | 画图服务是不是自己这台机器的，一般不用管 |

> `pageSize` 和 `searchMaxPreview` **别往大调**。QQ 里图片最宽只显示 420 像素左右，
> 一张图塞 24 个的时候每格才 70 像素，塞 80 个就只剩 35 像素、名字彻底看不清了。
> 想一次看全应该去网页版。

**只有「自己这台机器装了画图服务」的人才用得上：**

| 配置 | 默认 | 干什么的 |
|---|---|---|
| `reposDir` | 空 | 表情包仓库放在哪个目录。机器上已经有一份的话**必须填** |
| `repos` | 5 项 | 订阅了哪些表情包仓库 |
| `gitProxy` | 空 | GitHub 加速前缀，**建议留空直连** |
| `memePm2Name` | `meme` | 画图服务在 pm2 里的**名字**（不能填数字） |
| `deployPm2Name` | `meme-plugin` | `#meme部署` 装出来的那个服务叫什么 |
| `deployPort` | 2233 | `#meme部署` 装出来的服务用哪个端口。机器上已经有东西占着 2233 就改这里 |
| `pipIndexUrl` | 清华源 | 装 Python 包用哪个源 |

## 遇到问题看这里

**发了表情指令，机器人没反应？**
先发 `#meme开关` 看这个群是不是被关掉了，再发 `#meme部署状态` 看画图服务通不通。

**报「连不上」之类的错？**
说明画图服务没起来或者地址填错了。`#meme部署状态` 会把地址和具体原因一起告诉你。
自己这台机器装的话，八成是服务挂了，重启一下（pm2 里那个进程）。

**新拉的表情打不出来？**
新表情要走完三步才算数：下载 → 告诉画图服务「多了个目录」→ 重启画图服务 → 刷新插件里的列表。
`#meme更新` 会自动走完，如果不管用，先检查配置 `memePm2Name` 是不是真的等于 pm2 里显示的名字
（**必须写名字，不能写数字**，数字编号会随着进程增减错位，结果重启了别的服务，自己却毫无察觉）。

**刚重启完画图服务，立刻发表情说连不上？**
正常，等几秒。画图服务是**先扫完表情目录才开始接活**的，实测大概 7 秒。
这几秒里连不上不代表表情丢了，等它扫完就好。

**明明更新成功了，可新表情还是没有？**
经典情况：机器上有两份表情包仓库，你更新的是插件下的那份，画图服务读的是另一份。
把配置 `reposDir` 填成画图服务真正在用的那个目录（比如 `/opt/meme`）。

**网页版打不开？**
看日志里有没有 `EADDRINUSE`（端口被别的程序占了，换个 `webPort`）。
想让外网访问，`webUrl` 要填公网地址，端口要在防火墙放行。

**表情数量对不上？**
`#meme部署状态` 会同时显示服务那边和插件这边的数量，不一样就发 `#meme刷新`。

**卸载完了，列表里怎么还有表情？**
新版本已经处理了：卸载最后会再试一次连接，**连不上才**把本地列表和图片缓存一起清掉，
这样列表直接变空并告诉你下一步怎么做，而不是「看着满满的、一点就报错」。
如果你另外还有一套能用的画图服务，那些数据会原样留着，功能照旧。

**Windows 上部署说「缺少 pm2」/「需要 Python 3.9+」，可我明明装了？**
这是老毛病：机器人进程记住的是它**启动那一刻**的环境变量，你后来装的东西它看不见。
部署脚本已经会自己去注册表和常见安装位置找一遍，实在不行**重启一次 Yunzai** 就好了。

## 数据存在哪

都在 `Yunzai/data/meme-plugin/` 下面。删掉整个目录不会丢配置，只是列表和缓存要重新拉一次
（发 `#meme刷新`）。

配置文件 `config/config.yaml` 是你自己的，更新插件不会动它；万一改坏了，删掉它会从默认值重新生成。
